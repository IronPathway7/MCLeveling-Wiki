# Commands

### General Commands
| Command | Description |
| :--- | :--- |
| `/spawn` | Teleport to the main town |
| `/rtp` | Teleport randomly in the overworld |
| `/sethome [name]` | Save your current location |
| `/home [name]` | Teleport to your saved home |
| `/sys` | Opens the System menu |
| `/ah` | Open the Auction House |
| `/mail` | Send and receive mail |

### Party Commands
*   `/party invite [name]` — Invite a player to your party.
*   `/pc [message]` — Chat only with your party members.
*   `/party leave` — Leave your current party.
