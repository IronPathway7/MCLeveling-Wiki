# Land Claiming Guide (`/claim`)

### How to Claim
1. Type `/claim`.
2. Get the **Claim Wand**.
3. **Left-click** the ground with the wand.
4. If you like the area, proceed; if not, repeat step 2.
5. **Right-click** the ground to confirm.

### How to Expand
1. Get an **Expansion Token**.
2. Type `/claim` and get the wand.
3. Stand **inside** your claim.
4. Look in the direction you want to expand.
5. **Hold Shift + Left-click** toward that direction.

### Managing Trust
*   **To Trust:** `/claim` -> Left-click Claims Icon -> Trusted Players -> Click "+" -> Type name in chat.
*   **To Remove:** `/claim` -> Left-click Claims Icon -> Trusted Players -> Click player name -> Confirm.

### Other Actions
*   **Teleport:** `/claim` -> Right-click Claims Icon -> Wait 5 seconds.
*   **Delete:** `/claim` -> Left-click Claims Icon -> Delete Claim -> Confirm.
