## Premium Ranks

### Vessel (3000 Gems)
*   5 Homes / 5 AH Slots
*   Weekly Lootbox (1h XP Boost, 3x Keys, 10k Gold)
*   Commands: `/ptime`, `/pweather`, `/craft`, `/feed`

### Ruler (8000 Gems)
*   10 Homes / 10 AH Slots / 1x Class Change
*   Weekly Lootbox (3x 1h XP Boost, 5x Keys, 25k Gold)
*   Commands: All Vessel commands + `/furnace`, `/ec`, `/anvil`

### Monarch (12000 Gems)
*   20 Homes / 2x Class Change
*   Weekly Lootbox (8x 1h XP Boost, 10x Keys, 50k Gold, 50 Gems)
*   Commands: All Ruler commands + `/repair`, `/fly` (at spawn)

### Outer God (18000 Gems)
*   30 Homes / 3x Class Change / **No Teleport Cooldowns**
*   Weekly Lootbox (12x 1h XP Boost, 15x Keys, 100k Gold, 100 Gems)
*   Commands: All Monarch commands + `/heal`, `/hat`, `/sell all`
